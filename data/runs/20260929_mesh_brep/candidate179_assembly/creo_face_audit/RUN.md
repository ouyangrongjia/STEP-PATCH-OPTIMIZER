# Creo 往返后的实际拆面

针对用户截图中面边过多的问题，只核对已有 B 模型，没有修改拟合或显示设置。

用已导入的 `creo_final_B/import/b179_smooth.prt.1` 和 Creo 自带 `step_3d_export.ttd` 无图形再导出 STEP。整件 ADVANCED_FACE 实体由 **2695 增至 2703**；再读几何、定位 candidate-179 区域后，原来的 **5 张局部面对应 13 张面**：外围四片分别为 **3、2、3、4** 张，中央仍为 **1** 张。

此前“5 张面”是输入 STEP / OCCT 的面数，不能直接当作 Creo 转换后的面数。新增线中存在真实拓扑边，不能一概解释成 UV 参数线。查看 [同视角、仅显示真实拓扑边的对比](face_comparison.png)。

13 张面通过每面 7 个内部点投影到原五片定位，最大投影距离约 `4.16e-7 mm`，记录在 `face_localization.json`。各新增切分位置对应原 U 方向的重复节点：2 处三重节点、6 处二重节点。这些节点由精确原外边界的多段曲线拼接带入外围支撑面；并不是每个重复节点都发生拆面。该检查定位了分段来源，没有反推出 Creo 的内部拆分阈值，也没有仅凭截图识别所有线。

控制点数量是另一个维度：原纯网格 B 为 3125 点，精确接口适配后为 13375 点，最多单方向 152 点。它说明支撑表达偏重，但“控制点数”不等于“Face 数”。当前边界表达同时带来了控制点增长和 Creo 往返拆面，后续应针对这两项检查，不能通过隐藏边线宣称减少了面数。

原生 PRT 未修改；完整再导出 STEP 在系统临时目录 `candidate179_creo_face_audit_20260929/b179_smooth.stp`，不加入四个正式模型的交付目录。局部提取几何为 `creo_local.step`。导出任务及日志在 `export.dxc`、`export.json`、`export.*.txt`。一次对完整再导出几何的额外 BRepCheck 超过 120 秒 CPU 时间后停止；本次不新增“Creo 再导出后的整件有效性通过”结论，之前输入 STEP 的有效性记录保持原口径。
