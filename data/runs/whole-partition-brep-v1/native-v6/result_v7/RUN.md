# 共享边界与过渡曲面联合优化

本轮在原 359 个分区上完成公共边界与交点协调优化、局部退化回退、两侧支撑重拟合和实际单位法向联合优化。整件通过原距离预算和 Creo 安装配置检查，GEOM_CHECKS 为 0。仍有局部起伏，状态为 `DiagnosticOnly/can_apply=false`，不宣称达到商业软件整体质量。

## 产物

- `model.step`：最终整件；`regions/`：359 份开放分区件及原分区数据。
- `images/`：原 STL、上版与本版实际 STEP 同视角比较，以及 Creo 原生显示。
- `creo/`：实际导入 PRT、未修改安装配置副本及 ModelCHECK XML。
- `metrics/`：独立质量测量、失败记录、测试和一个 `reconstruction.zip`。

## 实测

直接对照为通过 Creo 检查的 `native-v4/result_v5`。历史 `native-v5/result_v6` 的 GEOM_CHECKS 为 1，原件保留。

| 检查 | 对照 | 本版 |
|---|---:|---:|
| 实际 STEP 面数 | 1092 | 1092 |
| 闭合实体 / 自由边 | 1 / 0 | 1 / 0 |
| 反向原生曲面采样 RMS，mm | 0.001577 | 0.001849 |
| 反向原生曲面采样 P95，mm | 0.003054 | 0.003697 |
| 反向原生曲面采样最大距离，mm | 0.025313 | 0.026766 |
| 面积协议相对源法向差 P95，° | 5.453 | 5.593 |
| Creo GEOM_CHECKS | 0 | 0 |
| 数字 3 平滑代理接缝法向差 P95，° | 24.841 | 3.074 |

552 条变化公共边界按同一源边链配对，总转角下降 22.8%，曲率平方积分下降 41.6%。这里的比例只针对变化链，不推广为全件光顺增益。法向比较使用源二面角不超过 10° 的代理光滑位置和弧长权重；曲线移动后位置改变，因此是同协议统计，不能据此宣告 G1/G2。

接缝的两侧法向差与拟合面相对原 STL 的法向差是不同指标。本轮公平化改善局部连接，但全局距离 RMS/P95 和相对源法向 P95 并非全面下降；平滑使用了原预算内的形状自由度，没有提高距离容差。

额外逐面请求 1024 个内部样本，实际核验 1117376 点，最大距离 0.029831 mm，仍在 0.03 mm 预算内。这套逐面均衡统计中，法向差 P95 为 10.862°，最大值 128.503°，大于 90° 的样本还有 3 个；不能以面积采样或接缝平均改善掩盖这些局部异常。全部 96 项后端测试通过。

## 问题原因与本轮改动

1. **分区标签没有携带光滑边界。** 上游 GUI 分区来自 STEP；冻结后映射为 STL 三角形标签，边界落在离散三角形边上。原 STEP 的光滑修剪线没有作为重建输入。即使两区分得正确，沿源边链直接描摹、固定所有交点，仍可能产生波浪。`network_fairing.py` 将公共边界控制点和相连交点一起优化，在有限源三角形距离管内移动；真实锐角和编辑范围外的连接固定。可证实为直线且两侧曲面相容的长边改用低复杂度直线表示。

2. **一条共有曲线只能解决位置闭合，不能自动解决横向过渡。** 原先相邻支撑面独立拟合，边界贴得很近，但从两侧离开边界的斜率不同，反光会断裂或形成细脊。`seam_fairing.py` 把两侧实际三维单位法向差加入同一求解系统，处理不同局部坐标系和尺度；按源折角排除应保留的锐边。保留源位置、域内探针和连续边界误差门，逐面回溯步长。它显著改善采样法向一致性，但没有施加处处精确 G1 或 G2 约束。

3. **短边和窄域会把很小的位置改变放大成曲率异常。** 本轮曾出现总量改善却有极短边被拉成卷曲的失败候选。交点回退也会把变化传给相邻边，不能只看回退前的全局能量。`network_support.guard` 在回退后逐条检查几何总转角、曲率平方积分、有限源域距离、裁剪绕序和连续交线；不合格边恢复基线，共享端点同步恢复，邻边用连续线性位移场协调，再重复检查。失败候选指标和回退记录保留。

4. **边界移动后必须重新验证两侧曲面。** 旧曲面可能不再覆盖新的修剪曲线，尤其是狭长矩形参数域。`network_support.refit` 先检查连续边界落面误差，只有仍相容的支撑可以复用，其余重拟合；失败邻域协调恢复后再次验证。`graph_reassemble` 拒绝带未处理边界变化标记的缓存，旧骨架续算入口拒绝重置已经移动的交点。

5. **位置误差小并不意味着没有凸起。** 凹字内壁、底部、圆滑过渡和粗网格折角混合，局部参数化、自由度分布、原始法向噪声都会影响曲率。此次使用源面积权重、物理尺度公平项和实际法向联合优化；没有只靠显示法向平滑改善截图。最终图使用实际 STEP 的一阶导法向、同一相机和光照，显示全部非退化 CAD 边。

本轮基于 NumPy、SciPy、OSQP、Shapely 和 Open CASCADE 实现，VTK 用于源三角形定位与可视化。没有调用 Geomagic API，没有使用参考 STEP 曲面或曲线来替代拟合。Creo 只承担独立导入和实体检查。

现阶段限制仍在分区后的几何布局：原有 359 个标签和源网格不变，未新增三角形，也未生成独立的过渡带布局。要进一步消除残余波纹，需要让边界网络、窄过渡带宽度及曲面参数化共同适配几何，并做曲率连续性约束；简单加密控制点或全网格拉普拉斯平滑不能单独保证这些条件。本轮结果只代表该参考件上的实测改善，不能推出任意模型或商业等效结论。

追加的牌面扩展实验将优化范围扩大到 264 个支撑并增强公平项，局部图像和接缝统计有所改善，但 Creo GEOM_CHECKS 从 0 增加为 1；逐面加密检查最大距离为 0.0300031785 mm，也超出固定的 0.03 mm 预算。因此最终保留通过原距离预算及零提示检查的前一候选，不放宽公差。这次变化只改支撑系数，没有改公共曲线；现有证据只能确定外部 CAD 回归与这批支撑变化有关，尚不能精确归因于某张面或某种曲率现象。完整候选系数、ModelCHECK 和对照图保留在压缩包，未用视觉改善掩盖交换失败。


## 复现与范围

解压 `metrics/reconstruction.zip` 至新目录，将 `source_snapshot` 加入 `PYTHONPATH`，执行 `python restore.py --stl <原始STL>`。恢复脚本逐项核验原网格坐标及三角形顺序，仅重绑定路径；`fit/` 和 `baseline_fit/` 保存精确系数。再运行 `python experiment_scripts/build_candidate.py fit <新输出目录>` 可重新装配、导出和检测本版模型。移动过交点的缓存禁止通过旧 `skeleton_reconstruct --from-fit` 重建骨架，以免悄悄复位交点。

归档中的 `rejected_plaque_fit/` 单独保存扩展牌面候选的精确系数及图像。这一候选使部分牌面更平顺，但新增 Creo GEOM_CHECKS=1，逐面加密最大距离也超出 0.03 mm，未采用；最终 `model.step` 对应 `fit/`，不能用该失败候选的 2.98° 接缝 P95 代替最终版本的指标。

本次采用缓存续算，精确配置、每阶段计时、失败及回退原因见实验记录，不把阶段之和当作冷启动耗时。重建未调用 Geomagic API，也没有读取参考 STEP 曲线或曲面作为拟合目标；输入分区仍源自原 GUI 的 STEP 分区映射。尚未将纯 STL 重新分区、新增过渡带布局和切网格集成到本版。

原始 STL、参考 STEP 和历史 native-v2/v3/v4/v5 保留。工作位于独立 whole-mesh-brep 工作树；主仓库的已有修改、C++ 产品与 GUI 不变。产出时未提交或推送；本次按版本单独归档。
