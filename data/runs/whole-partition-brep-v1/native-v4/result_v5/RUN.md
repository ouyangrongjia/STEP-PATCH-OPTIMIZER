# 数字 3 凹槽与过渡区优化结果

本轮整件为 **1092 面**，原 GUI 的 359 个分区及全部源三角形保持不变。数字 3 槽口的大块鼓包明显减轻，牌面长边有所改善；槽底和窄过渡仍有细波纹，192 区仍存在已复核的大法向偏差。整件通过独立距离抽样及实际 Creo 闭合实体检查，保持 `DiagnosticOnly/can_apply=false`，未通过全区域 G1/G2 或商业软件同等质量验收。

拟合和装配使用开源库与自写代码，不调用 Geomagic API，不读取参考 CAD 曲面。Creo 只用于独立导入检查及失败位置诊断。

最终面数比参考 2739 面少约 60%，比上一版增加 190 面，用于保留折角和字形。原 245568 个顶点、491132 个三角形及 359 个标签保持。Creo 活动实体有 1041 张曲面，与 OCCT 的 1092 张面分开报告。最大边容差为 0.00392699 mm，未扩大原 0.005 mm 边界预算。

本轮源距离预算仍为 0.03 mm，公共曲线到单侧支撑面的连续偏差预算为 0.002 mm。质量检查为 30000 个源样本及 109200 个反向原生曲面样本，不是认证 Hausdorff 上界。反向样本数随实际面数变化，不能将微小统计差异解释为严格配对消融。

**法向极值仍未通过光顺要求。** 反向样本中有 1 个与最近源三角形法向相反，最大角差 117.1368°；定位到 192 区，回读 STEP 的采样面索引为 572。限定到自身源域后仍为 115.7082°，不能解释为最近标签误配。该支撑未被最后的 137 区距离修复改变，完整位置和复核保存在 `metrics/diagnostics.json` 的 `normal_extrema_diagnosis`。低 P95、有效实体及零 GEOM_CHECKS 不代表全局光顺。

OCCT 回读体积为 688.5903 mm³，Creo 原生查询约 690.246 mm³；保留这一差异，不作体积保持声明。原始阶段状态见 [pipeline.json](metrics/pipeline.json)，后续外部 Creo 证据单独保存，不回写改变原始阶段事实。

## 方法与历史试验

1. **源折角分域。** 原焦点布局中有 550 条大于 30° 的源折角位于光滑支撑内部。按源折角划分拟合域后，大块圆鼓明显减少；保留源标签和坐标，未把源折角直接认定为 CAD 语义特征。
2. **精确平滑能量与面积加权。** 修正双三次样条平滑项的二点 Gauss 欠积分，用四点一维 Gram 矩阵精确组合；位置和法向目标加入三角形面积权重。单独修正积分的局部效果有好有坏，不能将全部鼓包归因于此。
3. **原网格距离管内的边界优化。** 新公共曲线在原始相邻源域的 0.003 mm 距离管内优化，并连续检查区间；原始折线位移仍不超过 0.12 mm。相同数值预算下，检查定义由固定关联平面改为原网格距离，二者不宣称等价。最终可与原链配对的 27 条新曲线，其参数弯曲能量之和由 317.268 降为 92.915，仅描述该子集。
4. **保留失败结论。** 单独增加平滑权重、去掉法向目标、仅作源域公平化、三阶导能量均未充分解决槽口鼓包；提高边界法向权重反而产生明显新波纹，未采用。12° 法向约束试验因大量拟合失败而中止，不代表数学不可行证明。

整件试验包含以下未采纳候选，其原始配置、指标、导入结果和脚本文本汇总在 `metrics/experiments.json`：

- `whole_candidate`：895 面，原协议抽样及 Creo 导入通过；后续同域加密采样发现继承的距离反例，因此不再作为全部已知距离检查均通过的候选。
- `whole_features`、`whole_features_repaired`：均为 1128 面，几何抽样通过，但实际 Creo 为零活动实体，修复后仍失败。
- `whole_focused`：20 个焦点区域保留源折角分域，78、192 区保留较粗布局；1091 面通过 Creo，但独立抽样最大值 0.0300199695 mm 超过 0.03 mm，正确判为失败。
- `whole_final`：定位到 137 区旧支撑的距离极值后，仅重算 3 个支撑、复用 1089 个，得到本次 1092 面交付。固定 10 万源面积样本的支撑到原网格最大距离由 0.0308422 降到 0.0276203 mm；这项补查不冒充裁剪 STEP 验收。

最终缓存修复入口含装配、导出、几何检查和区域导出共 668.95 秒，另一次 Creo 验证为 275.61 秒。局部试验有不同缓存和重算范围，阶段时间不代表全部探索耗时、冷启动性能或算法加速比。

## 验证、复现与整理

既有 Python 后端回归 **76 项通过**，见 [测试日志](metrics/tests.log)。图片来自实际 STEP 的原生 D1 法向，采用一致的相机、材质和光照；全部非退化 CAD 边均显示。原网格的折面仍可见，没有通过显示法向平滑改变对照结果，见 [视觉检查及渲染参数](metrics/visual_review.json)。

本次目录整理只复制已验证的产物，逐字节核对整件、分区件、Creo 文件和保留的原始指标，并核对源三角形恰好覆盖一次、原标签不变。没有重新拟合，也没有修改几何结果，记录见 [交付核对](metrics/delivery_validation.json)。

环境保存在 [environment.json](metrics/environment.json)，算法入口和参数用法见 [工具说明](../../../../../tools/mesh_brep/README.md)。`regions/source_partition.npz` 保留完整输入分区，`metrics/chart_layout.npz` 保留最终精确三角形归属。历史试验的参数、失败结论和辅助脚本文本已集中归档；拟合缓存清理后不能直接使用其中的旧 `--from-fit` 路径续算，也未宣称重新冷运行会精确回放本交付。

中间模型、重复图、逐轮缓存和过程日志按前两版方式移入 Windows 回收站，见 [整理记录](metrics/cleanup.json)。旧 `native-v2`、`native-v3`、原始 STL、参考 STEP、代码及其他工作树保持。原始测量中的历史绝对路径仅标记来源，当前可打开产物以本说明和 `run.json` 中的相对路径为准。

剩余目标是处理 192 区局部大法向偏差，协调光滑接缝导数与小面交换稳定性，并在其他模型上复验。C++ 产品、GUI 和 Apply 门未改变。
