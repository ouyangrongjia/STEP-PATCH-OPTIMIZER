# 原生局部 AutoSurface 实验结论

## 当前状态

`native-autosurface` 冻结为四边布局实验参考，不再继续实现 AS-3，也不接入 GUI 或 `AppController`。历史分支和提交关系由 Git 保存。

AS 代码只用于探针、测试和按需移植；它不是 `native-surface-reduction` 的运行路径。

## 冻结原因

AS-1 以从 STEP 采样得到的全局三角网络为拓扑、布局和参数化前提。真实 STEP 已证明该三角网络质量不足，继续实现 AS-3 只会把输入缺陷传给曲面网络拟合器，无法满足原始 B-rep 形态与拓扑质量门。

允许按需移植的内容仅限：

- 与原始面局部自适应采样有关、且不依赖全局三角拓扑的独立逻辑；
- 报告格式和诊断辅助代码；
- 不包含 QuadriFlow、多图参数化或全局三角邻接假设的测试工具。

重新启用前必须先证明输入拓扑质量、多图接缝和跨内核质量门可以形成可复现基线，不能通过真实样例特判恢复。

当前替代路线见 `surface_reduction_guide.md`。
